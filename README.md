# Studentische Angebote an der HAW Hamburg

> Eine Übersicht über studentische Projekte, Initiativen, Hochschulgruppen und Engagementmöglichkeiten an der HAW Hamburg.

## Warum mitmachen?

Neben dem Studium bieten zahlreiche Initiativen, Projekte und Gruppen die Möglichkeit:

- neue Leute kennenzulernen
- praktische Erfahrungen zu sammeln
- Soft Skills zu entwickeln
- technische Fähigkeiten auszubauen
- Verantwortung zu übernehmen
- den Lebenslauf zu stärken
- einen Ausgleich zum Studium zu finden
